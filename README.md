# NeuroForge BioMaterials

Демо-прототип: КТ черепа + данные пациента → пористый каркас-имплант по форме дефекта свода → STL и 3D-просмотр.

Режимы:
- **КТ черепа (3D)**: zip с DICOM-срезами или NIfTI (.nii / .nii.gz). Для здоровой КТ есть переключатель «Смоделировать дефект».
- **Картинка (упрощённо)**: любой PNG/JPG, универсальный пористый кубик.

Локальный запуск:

    pip install -r requirements.txt
    uvicorn backend.app:app --port 8000
